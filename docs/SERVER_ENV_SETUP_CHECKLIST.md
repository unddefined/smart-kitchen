## 🚨 故障排查

### 问题 1：部署失败 - Secrets 未找到

**错误信息：**
```
Error: Input required and not supplied: key
```

**解决方法：**
1. 确认 `SSH_PRIVATE_KEY` Secret 已正确添加
2. 检查私钥格式是否完整（包含 BEGIN 和 END）
3. 重新添加私钥，确保没有多余空格

### 问题 2：数据库连接失败

**错误信息：**
```
Can't reach database server at `8.145.34.30:5432`
```

**解决方法：**
1. 检查 `DATABASE_URL` 格式
2. 验证数据库密码是否正确
3. 如果密码包含特殊字符，需要 URL 编码

### 问题 3：.env.production 未生成

**检查步骤：**
```bash
# SSH 登录服务器
cd /root/smart-kitchen

# 查看文件列表
ls -la .env*

# 如果没有 .env.production，手动创建
nano .env.production
# （复制上面的预期内容）
```
